## Design

1. **Page form.** tools/site_build.py wraps each brief's inner HTML in `<template class="axl">` (idempotent: an
   already wrapped page is unwrapped first). The `.brief` element keeps its id, classes and data attributes, so shelf
   filters, the sidebar, counts by attribute and links to a brief id find it. Brief bytes inside the template are
   unchanged; tools/pagelib.py `briefs()` reports the inner HTML inside the template, so every brief tool reads the same
   bytes as before.
2. **Runtime (site/js/core.js, AX.brief).** `AX.brief.each(fn)` registers a per-brief pass (run in registration order on
   every brief when it is built, and at once on briefs already built); `build(b)` moves the template content into the
   brief, runs the passes, emits `brief:built`; `ensure(idOrEl)` builds the brief holding an id (a brief id or any id
   inside a template); `content(b)` returns the built brief or the template content (inert, for readers that need every
   brief: search, Review counts, NBME counts and lists, title maps).
3. **Loader module (site/js/06-load-near.js, replaces 06-render-near.js).** Builds briefs within about 1.5 screens of
   the viewport (IntersectionObserver), the hash target on load and on hashchange, the target of any in-page link
   before the browser jumps, and every brief when IntersectionObserver is missing, in jsdom, or with `?axall` (tools).
   Unbuilt briefs hold an estimated height; a brief built above the viewport keeps the reader's place (native scroll
   anchoring where supported, a scroll correction otherwise). Built briefs keep content-visibility with their measured
   height, as 06-render-near did.
4. **Modules.** Every pass that walks brief content at load becomes a per-brief pass through `AX.brief.each`.
   Document-wide setup (listeners, observers, the toolbar, the sidebar) stays at load. Readers of every brief use
   `AX.brief.content(b)`; features that need built content of other briefs (drawers, previews, Review quiz items,
   search landing) call `ensure` first.
