## Design

1. **Page form.** tools/site_build.py wraps each brief's inner HTML in `<template class="axl">` (idempotent: an
   already wrapped page is unwrapped first). The `.brief` element keeps its id, classes and data attributes, so shelf
   filters, the sidebar, counts by attribute and links to a brief id find it. Brief bytes inside the template are
   unchanged; tools/pagelib.py `briefs()` reports the inner HTML inside the template, so every brief tool reads the same
   bytes as before.
2. **Runtime (site/js/core.js, AX.brief).** `AX.brief.each(fn)` registers a per-brief pass (run in registration order on
   every brief when it is built, and at once on briefs already built); `build(b)` moves the template content into the
   brief, runs the passes, emits `brief:built`; `ensure(idOrEl)` builds the brief holding an id (a brief id or any id
   inside a template); `content(b)` returns the built brief or the template content (inert, for readers that need every
   brief: search, Review counts, NBME counts and lists, title maps).
3. **Loader module (site/js/06-load-near.js, replaces 06-render-near.js).** Builds briefs within about 1.5 screens of
   the viewport (IntersectionObserver), the hash target on load and on hashchange, the target of any in-page link
   before the browser jumps, and every brief when IntersectionObserver is missing, in jsdom, or with `?axall` (tools).
   Unbuilt briefs hold an estimated height; a brief built above the viewport keeps the reader's place (native scroll
   anchoring where supported, a scroll correction otherwise). Built briefs keep content-visibility with their measured
   height, as 06-render-near did.
4. **Modules.** Every pass that walks brief content at load becomes a per-brief pass through `AX.brief.each`.
   Document-wide setup (listeners, observers, the toolbar, the sidebar) stays at load. Readers of every brief use
   `AX.brief.content(b)`; features that need built content of other briefs (drawers, previews, Review quiz items,
   search landing) call `ensure` first.

5. **Search (chat 2).** An unbuilt brief's search record is read from `AX.brief.copy(b)`: a detached copy of its
   template run through every registered per-brief pass, so text, block labels and masks equal the built brief; the
   copy is dropped and each block keeps its masked ranges (`k.mr`) for snippets. On `brief:built` the record is read
   again from the page. Landing on an unbuilt hit builds the brief, searches again and lands on the fresh hit. The
   index skips the bounds chrome (`.bb-bar`, `.bb-rail`, `.bb-end`), which the bounds pass adds only in the page.
6. **Shared readers in core (chat 2).** `AX.brief.items(b)` (bank cards of a built brief, or the template items the
   build turns into cards; type and status), `AX.brief.qtype(t)` and `AX.brief.prompt(t)` (the question-type table,
   moved from the transform). Review (pool, unavailable count) and the blueprint read items through it.
7. **Events (chat 2).** `brief:built` (core, after a build). `brief:reveal {y, smooth}` (loader): scroll to y();
   observer builds wait until the scroll stops, then resume, and the page is re-placed at y() until it holds; reader
   input ends the correction. Search landing emits it. The sidebar rail waits for `brief:built` of the current brief.

8. **Prebuilt search index (chat 3, D-20261106-4).** tools/search_index.js loads the page with `?axall` (Math.random
   seeded, so the bank option order and the file are byte-stable) and writes `__axSearch.dump()`: per brief {id, title,
   sub, blocks [[label, rank, bank, raw, mr, stemEnd]]}, the alias groups and the one-way aliases; mask ranges run
   across one collapsed space (3.81 MB, 1.04 MB gzipped). site_build.py writes search.json beside every wrapped page it
   builds (`--no-index` skips); ship.sh deploys it to discriminator-briefs-site/ (workspace/search.json untracked); the
   gate's `search-index` check fails when the file is missing or differs from a fresh dump. The page fetches
   `search.json?v=<build>` once the loader settles (requestIdleCallback, 3 s), or at the first query; a query before it
   lands shows "Loading search…" and runs when it lands; records of briefs already built are read from the page; a
   failed fetch, a file that does not list this page's briefs, or a page opened from disk falls back to the chunk 2b
   in-page build, with a note under the results. With every brief built (`?axall`) the page builds from the page.
9. **Long jumps (chat 3).** `brief:go id` (18 sidebar): a jump takes the sidebar's own path (the hash, then the target
   seated until it holds). 07 drawer links emit it; in-page links to another brief ("Pairs with" cross-references,
   links in brief text) go through it from a bubbling click listener (links whose handler already acted arrive with
   the default prevented). Cause: a smooth hash scroll across about 325,000 px of unbuilt briefs overshot as the
   briefs it passed built (drawer jump landed 76 px above its target; a cross-reference 1,699 px below in one run).
