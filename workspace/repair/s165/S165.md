## Design

1. **Worker (site/pwa/sw.js; built to discriminator-briefs-site/sw.js).** tools/site_build.py writes it beside the page,
   minified, opening with `var BUILD="<ax-build stamp>"`; ship.sh rewrites it after stamping (`site_build.py --pwa-only`),
   so every ship is a new worker and a new cache `step2haki-<build>`. The site bundles are inline in index.html, so the
   saved set is: the page (stored under the scope root, after checking its ax-build stamp equals BUILD), search.json
   (fetched as `search.json?v=<build>`, the page's own request, so the first visit reuses the HTTP cache),
   manifest.webmanifest and the 4 icons. Activate deletes every other `step2haki-` cache and claims open pages.
2. **Requests.** Page navigations (`/`, `/index.html`, any query or hash) and search.json: saved copy first, network if
   missing; a `?v=` naming another build goes to the network first (the old reload-to-build link still reaches a newer
   page). version.json, sw.js and api/ (Review sync) are never intercepted. Cross-origin requests are untouched.
3. **Updates.** 24-offline registers sw.js (`updateViaCache: 'none'`) after load at idle. The browser checks sw.js on
   each navigation; 04-version's version.json check (4 s after load, on return to the tab, and now on the online
   event) emits `site:newer`, and 24-offline calls `registration.update()`. When the new worker has saved the new build
   it waits; 24-offline emits `site:ready` and 04-version shows the existing bar "A newer version is available.
   Refresh". Refresh emits `site:apply`: the waiting worker takes over and the page reloads on controllerchange. A page
   with no worker keeps the old path (reload to `?v=<build>`).
4. **Offline note (site/js/24-offline.js; components/offline.css look, layout/offline.css position).** Shown while
   `navigator.onLine` is false, or after a version.json request fails (04-version emits `net:status`; this covers weak
   signal where the device still reports a connection). Text: "Offline: saved copy from Nov 6, 2026" (the page's build
   day); with no saved worker, "Offline: no saved copy on this device". A dark glass pill matching the INDEX tab
   (tokens --t-axoffline-*, dark theme values from the navtab tokens), a 7 px dot in --mhi-e; desktop bottom right,
   narrow and phone bottom center above the bottom bar; spring timing; hidden again on the online event or a
   successful check.
5. **Install.** site/pwa/head.html tags (theme-color, mobile-web-app-capable, apple-mobile-web-app-capable and title,
   manifest, icon, apple-touch-icon) replace any earlier copy after the title; `site_build.py --check` (gate) also
   checks them. Manifest: name and short_name Step2Haki, start_url and scope "./", display standalone, background and
   theme #EFF0F0. Icons drawn from the sidebar brand mark ("S2", 800 weight, white on #15151B, tile radius 11/38) by
   repair/s165/make_icons.js: 192 and 512 with the mark's rounded corners, maskable 512 and the 180 apple-touch icon
   full bleed.
6. **Tools.** serve_page.js serves .js, .webmanifest and .png with their types and maps /index.html to the page;
   `srv.use()` switches the served page. ship.sh: offline files after the stamp, copied beside the deployed page,
   added to the commit, restored on a failed ship.
