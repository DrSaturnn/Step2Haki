Pause point formats

The live pause point, then the same content broken into lines the way practice questions are: a bold setup line, indented lines on the accent rule, and an arrow to the answer.

Recommended: question style. Each bait gets its own block: the setup in bold, then two indented lines on the accent rule (what it is offered as, in caution; then the deciding feature), then an arrow to the answer. Anything else goes in one muted line underneath. In study mode the answer is masked like a practice item's key.

Compact rows. The shortest form: one row per bait with the wrong answer struck and the right one beside it. Fastest to scan, but the deciding feature drops out, so it teaches less.

Either way the wording is split into lines, so a rollout re-reviews every pause point's text (about 105 briefs).
