## Recipe per brief (what the peds-uti-recurrent build did; continuation chats follow it)
1. Folder: merge briefs use repair/migration/merge/<id>/spine; the others repair/migration/peds/<CODE>/spine (new).
   `python3 tools/spine/dump_lines.py <id> <folder>/live_lines.json > <folder>/live_lines.txt`;
   `python3 tools/spine/bank_items.py <id> 100 k` (keys) and `... <id> 170` (stems).
2. `python3 tools/spine/board_index.py show <id> --cards 200 > <folder>/board_show.txt`; read the question items it
   names (repair/sources/s*_questions.md, grep the header) and the card list compactly; full card text and high-yield
   lines from repair/sources/anki/anki_index.jsonl by nid.
3. MSD pages: fetch.py (cache in repair/sources/web); five guessed URLs were 404, so find the real URL with WebSearch
   first.
4. facts_spec.json (cards, local, web) -> `python3 tools/spine/facts_from_spec.py <folder>/facts_spec.json`.
5. build.py on the pyelo (disease) or polyuria (hub) pattern; `python3 build.py` prints claims and words.
6. `python3 tools/spine/card_dispositions.py make <id> <folder>`; `python3 tools/spine/card_autocover.py <folder>`;
   write cards_disposition.json (auto covered plus the rest by hand; statement-level keys settle warnings); `check`.
7. `python3 tools/spine/shingle_runs.py <folder>`, reword, rebuild; `python3 tools/spine/verify.py <folder> --mech --fast`.
8. boards.md, cuts.json; copy the folder into step2haki-private local-only/ (branch wip/s147) and push; batch file line.
