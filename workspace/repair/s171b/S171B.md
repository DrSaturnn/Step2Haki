## Design

- tools/stamps.py: one store, local/stamps/<check>/<name>.json (untracked, container-only like the approval record);
  a stamp keeps the last 5 passing keys; each key is a sha256 per input group; a miss names the changed groups;
  AX_STAMPS=off forces every check.
- Groups: tools (every .py, .js, .sh under tools/ except hooks/ and plugin/, repair/build.py, package-lock.json, node
  and Python versions); tool-data (tools/**/*.json, .txt, .csv, .md, tools/tests/; the perf and a11y baselines belong
  to ui_gate alone); docs (DECISIONS_DIGEST, STANDING_DIRECTIONS, BATCH_RUNBOOK, ui/UI_MAP.md: the private docs the
  tools read); rules (repair/efficiency top-level .json and .md minus the run records WAVE.json, style_audits.json,
  context_baseline.json, STATE_ARCHIVE.md, RESULTS.md; rules sheets); site; sources (repair/sources, content hash,
  about 128 MB in 1,367 files, under a second); page, base page (shells, retirements, wave id, HEAD index blob).
- verify.py: a full run (no --fast, no --mech) that ends READY writes the folder's stamp, keyed before and after the
  run (inputs that moved during the run: no stamp). Folder logs (verify_all.log) are not inputs. The tracked tree that
  verify's preview vendor_scan reads is left out: ship.sh's vendor-scan and vendor-orphan cover it at every ship.
- ready_gate.py: per spine build, stamp hit = READY without verify; miss = names the changed groups, runs verify.
- ship.sh: stamps on rules-migrate, rules-gate, gate (page bytes, search.json, HEAD index blob or --attr-only ref),
  render, vendor-scan (tracked tree and sources), vendor-orphan (page, tree, sources). Build, site_build, approval,
  build stamp, changelog, local-only and preflight (advisory) run every time.
- ui_gate.py: each test's pass is a stamp (page, base, allow, views, tools, package-lock and node); theme keeps
  style_surface's record.
